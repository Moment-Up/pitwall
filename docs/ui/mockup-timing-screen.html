Pitwall · Direction A · Timing screen minimal

Static mockup for docs/ui/proposal-timing-screen.md. It shows the iPad-landscape Drive › Dash screen in every state, the four-area navigation (iPad rail and phone tab bar) and one Review page. The device frames are drawn at real CSS pixel size (iPad 1180 × 820, phone 390 × 844) and scaled down to fit your window.

SAMPLE DATA: every number, name and message here is illustrative. None of it comes from a real session.

1 · Drive › Dash · iPad landscape at about 70 cm

One focal number (the delta to your reference lap). The next corner, using the official name only when the hand-verified track sheet has one, and the distance to the reference braking marker. Timing cells with a coloured top bar. A linear lap strip instead of a map. The rail and status bar dim while you are on track. Panels never move: states only change what is inside them.

  1. 1Status bar. Connection, evidence tier (synthetic / replay), track and session, the latest radio line, radio pill, night dim. Banners (yellow, safety car, link lost) take over this row.
  2. 2Delta hero. 172 px, tabular, 2 decimals, at most 10 updates a second. Sign, AHEAD/BEHIND word and bar direction repeat the colour. It reads delta_s and the reference lap.
  3. 3Next corner. The first corner whose apex is ahead. Official name only from the verified sheet. The brake-marker distance comes from cues.next.in_m. It never flashes "brake now": the radio does the timing.
  4. 4Timing strip. LAP clock, S1-S3, LAST, BEST. 6 px top bar plus a BEST/PB micro-label. Toggle "Tier 2" to see what ships first (last lap's sectors).
  5. 5Lap strip. Linear lap from the game's own sector boundaries and the learned corners, with the car, the next cue's braking zone and live yellow zones.
  6. 6Rail. Four areas. 80 px wide with 76 px targets. Dimmed to 40 % on track, and any touch restores it. Driver avatar and connection dot at the bottom.

Type stand-in: this mockup uses fonts already on Apple devices (DIN Condensed, Avenir Next Condensed). The proposal self-hosts Barlow Semi Condensed (SIL OFL) so every device looks the same offline.
